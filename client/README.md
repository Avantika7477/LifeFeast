# LifeQuest client

React (Vite) frontend for LifeQuest.

From the repo root:

```bash
npm install
cp client/.env.example client/.env   # if you do not already have one
npm run dev
```

App: [http://localhost:5173](http://localhost:5173)

Lint: `npm run lint`  
Production build: `npm run build`

Full setup, env vars, and demo accounts are in the [root README](../README.md).
